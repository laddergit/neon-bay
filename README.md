Neon Bay is an original top-down 2D open-world crime game in the style of GTA 1/2: steal cars, outrun the police across 5 wanted levels, and play a 6-mission story as Rex Vega in the fictional city of Neon Bay. Pure Canvas + JavaScript with zero dependencies; runs in any desktop browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
